# Recorded Step Ledger

Each completed project step is recorded with a self-reported UTC timestamp generated by Python:

```python
from datetime import datetime, timezone
print(datetime.now(timezone.utc).isoformat(timespec="microseconds"))
```

These stamps are convenience markers, not cryptographic signatures. The authoritative, tamper-evident publication history is the Git commit history itself; a stamp reports completion only after its corresponding GitHub commit is verified.
