# Roadmap

## 0.1 release candidate

- Normative schema and dependency-free validator
- Multiple compositional examples
- Public counterexample and independent-validator challenges
- CI, governance, licensing, security, and release evidence

## 0.2 evidence phase

- Census at least 100 materially distinct software families
- Publish ambiguity, coverage, and root-necessity measurements
- Complete bidirectional mappings to SWHID, SPDX, purl, and SWID
- Receive one independent validator implementation

## 0.3 blueprint phase

- Bind canonical seeds and generator identities to verified source artifacts
- Replace placeholder example identifiers with resolvable artifacts
- Demonstrate deterministic source and build reproduction

## 1.0 proof threshold

- Zero unresolved counterexamples in the declared census
- Operational distinction and independent necessity evidence for every root
- Published migration and extension policy
- At least two independent implementations
- Shared technical governance
