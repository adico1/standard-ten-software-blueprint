# Release Checklist

- [ ] Specification status and version agree.
- [ ] JSON Schema parses and matches the declared version.
- [ ] Every example passes the validator.
- [ ] All unit and mutation tests pass.
- [ ] Required community, governance, security, and license files exist.
- [ ] Prior-art mappings do not claim replacement of existing standards.
- [ ] Changelog includes the release.
- [ ] Stamp ledger contains the release-readiness stamp.
- [ ] GitHub Actions passes on the release commit.
- [ ] Release notes explicitly distinguish implementation validation from proof of taxonomy completeness.
